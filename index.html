📋 Flujo de Trabajo Diario

Contexto · Sesión · Memoria

💡 Pro tip: Usa /plan para explorar opciones sin tocar código. Luego /memory para que Claude no olvide tu contexto.
/plan
Entra en modo planificación — Claude propone sin tocar archivos. Perfecto antes de empezar
/memory
Crea y actualiza notas para que Claude recuerde tu proyecto
/context
Ve cuánto contexto usas y cuánto te queda disponible
/compact
Libera contexto resumiendo la conversación — mantiene lo esencial
/resume
Reanuda una conversación anterior por ID o nombre
/clear
Inicia una conversación nueva con contexto vacío
/copy
Copia la última respuesta del asistente al portapapeles
/export
Exporta la conversación actual como texto plano
/focus
Mira solo lo importante: tu último prompt y cambios clave
/skills
Lista las skills disponibles — automatización de tareas repetidas
/diff
Abre un visor interactivo de cambios realizados
/effort
Ajusta el nivel de esfuerzo (low/medium/high/xhigh/max)
/fast
Activa modo rápido (velocidad sobre profundidad)
/recap
Genera un resumen breve de la sesión actual bajo demanda
/btw
Pregunta lateral sin afectar la conversación principal
Perfecto para dudas rápidas sin perder contexto
/voice
Activa dictado por voz (modos hold, tap u off)
/rewind
Vuelve la conversación o código a un punto anterior
Salva cuando te arrepientes de algo

⚡ Avanzado

Razonamiento · Automatización · MCPs

Modos de Razonamiento

think
Razonamiento estándar (por defecto)
Uso: think: tu prompt aquí
think hard
Más deliberado — para decisiones de arquitectura
think harder
Profundo — para sistemas complejos o trade-offs

Automatización y Loops

/loop <intervalo>
Ejecuta un prompt repetidamente mientras dura la sesión
Ejemplo: /loop 5m /audit
/schedule
Crea, edita o ejecuta routines programadas
/agents
Gestiona configuraciones de subagentes paralelos

MCPs para Diseño

Figma MCP: Acceso a capas, variables y screenshots desde Figma sin tocar la app
Linear MCP: Consulta tickets activos y estado del sprint
Notion MCP: Leer/escribir docs de diseño, briefs y specs
Playwright: Claude navega el navegador para testear UI en vivo

Diagnóstico y Costos

/status
Abre Settings con versión, modelo, cuenta y conectividad
/usage
Costo de la sesión, límites del plan y estadísticas
/rewind
Vuelve la conversación o el código a un punto anterior
